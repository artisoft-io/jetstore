The User Guide is for the people who configure and run JetStore day to day: knowledge engineers who
write the rules and pipeline configurations of a workspace, and analysts who load files, start
pipelines and read their results.

It is organised by what you need at the moment you open it:

- **Concepts** explain the ideas JetStore is built on: clients, organisations and object types;
  source configurations and domain keys; files and the input registry; workspaces and what they
  hold; pipelines, sessions and their statuses; the rule engine; users, roles and capabilities.
- **Tutorials** teach by doing, start to finish: from a new file to a pipeline's output, or a first
  rule change, compiled and tested.
- **How-to guides** reach one goal each: load a file and map its columns, start and watch a
  pipeline, find a process error, query the data, work on a workspace, delete a session.
- **Screens** describe each screen of the application and each user flow, one page apiece. The
  *Help* button in JetStore's top bar opens the page for the screen you are on.

This guide is being written. Until its pages arrive, the [Developer's Guide](/docs/developer/)
describes how JetStore works and the [Installation Guide](/docs/install/) how it is deployed.
