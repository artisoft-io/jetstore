Each guide reaches one goal: what you need first, the steps, and how to tell it worked. They assume
you know the ideas in the [concepts](/docs/user/concepts/); for every column and button of a screen,
see its screen page. To learn the tasks for the first time, start with the
[tutorials](/docs/user/tutorials/).

| Guide | Goal | Capability |
|---|---|---|
| [Load and map a file](/docs/user/how-to/load-and-map-a-file/) | check a new file arrived, load it, check its columns and mapping, and map it | `run_pipelines` |
| [Look at loaded data](/docs/user/how-to/look-at-loaded-data/) | browse the rows of a loaded file or of a table a pipeline wrote | `jetstore_read` |
| [Run a pipeline](/docs/user/how-to/run-a-pipeline/) | start a pipeline, watch it, and run it again | `run_pipelines` |
| [Read a run's process errors](/docs/user/how-to/read-process-errors/) | find the errors a run raised and the records behind them | `jetstore_read` |
| [Query the data](/docs/user/how-to/query-the-data/) | run a query, or a statement that changes the database | `workspace_ide` |
| [Work on a workspace](/docs/user/how-to/work-on-a-workspace/) | edit a workspace file, compile, commit, pull, and revert a change | `workspace_ide` |
| [Run rules unit tests](/docs/user/how-to/run-rules-unit-tests/) | run a workspace's rules unit tests and read their results | `workspace_ide` |
| [Run a runbook](/docs/user/how-to/run-a-runbook/) | run a workspace runbook, answering the steps that wait for you | `runbook_execute` |
| [Delete a session](/docs/user/how-to/delete-a-session/) | delete a session and everything derived from it | `delete_session` |
| [Manage users](/docs/user/how-to/manage-users/) | activate an account, give it roles, or delete it | `user_admin` |

[Users, roles and capabilities](/docs/user/concepts/users-and-capabilities/) says which roles grant
each capability.
