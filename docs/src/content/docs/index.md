JetStore loads client files, maps them to a domain model, runs them through rules and compute
pipelines, and writes the results to tables and files. These pages describe the version of JetStore
you are running: an installation serves the documentation that was built with it.

The documentation is in three guides, one for each kind of reader.

## [User Guide](/docs/user/)

For the people who configure and run JetStore: knowledge engineers and client analysts. Concepts,
tutorials, how-to guides for everyday tasks, and a reference page for each screen.

## [Developer's Guide](/docs/developer/)

For engineers who extend or maintain JetStore: its architecture and the reasons behind it, how to
add a compute-pipes operator, a custom Lambda, a system table or a screen, and the reference pages
generated from the code.

## [Installation Guide](/docs/install/)

For whoever deploys JetStore into an AWS account: planning a deployment, deploying and upgrading it,
and the stack parameters, environment variables and images involved.

Use the search box at the top of every page to search all three guides by keyword.
